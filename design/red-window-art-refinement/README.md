# Red Window Art 首页精修素材包 v0.2

这个压缩包用于帮助 Trae / DeepSeek 在现有 `yuxian-paper-art` 项目中，继续把首页精细化到接近设计稿的风格和完成度。

## 适用场景

- 你已经有一版首页
- 但当前页面还比较“骨架化 / 占位化”
- 需要进一步贴近最终设计稿
- 开发代理不具备设计与规划能力，需要“无脑执行”式任务说明

## 包内内容

- `assets/reference/`：目标设计稿与当前实现截图
- `assets/generated/sheets/`：我生成的整段素材图
- `assets/generated/crops/`：已切好的单张素材图，可直接用于卡片
- `assets/vectors/`：可直接复用的图标和 logo SVG
- `assets/tokens/`：颜色、字体、布局设计令牌
- `docs/`：设计说明、素材清单、切图指引、Trae 详细任务书、验收清单

## 推荐目录放置

建议把整个包解压后放到项目根目录：

`design/red-window-art-refinement/`

## 最重要的文件

直接把下面这个文件发给 Trae：

`docs/03-trae-task-pack-homepage-v2.md`

如果希望 Trae 完全照着做，不要删减其中的任何要求。
