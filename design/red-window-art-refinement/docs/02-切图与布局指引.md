# 02 切图与布局指引

## 1. Hero

- 使用：`hero-scene.png`
- 显示位置：首页首屏右侧
- 建议容器比例：接近 4:3 或 1.25:1
- 实现方式：可直接 `next/image` 填充，也可作为容器背景图

## 2. Featured Collections

优先直接使用裁切后的单张图片：
- `collection-zodiac.png`
- `collection-blessing.png`
- `collection-wedding.png`
- `collection-framed-wall-art.png`

推荐卡片顺序：
1. Zodiac Collection
2. Blessing Collection
3. Wedding Gifts
4. Framed Wall Art

推荐图片比例：约 4:3

## 3. Craft Story

- 使用：`craft-story-banner.png`
- 建议整块横向使用
- 左侧展示手工过程
- 右侧叠加文字内容
- 右侧本身已留有浅色留白区域

## 4. Meaningful Chinese Gifts

优先使用：
- `gift-housewarming.png`
- `gift-wedding.png`
- `gift-lunar-new-year.png`

推荐顺序：
1. Housewarming
2. Wedding
3. Lunar New Year

## 5. Featured Artworks

优先使用：
- `artwork-dragon-of-prosperity.png`
- `artwork-blessing-of-fortune.png`
- `artwork-peony-of-abundance.png`
- `artwork-mandarin-ducks.png`

推荐卡片比例：接近 4:5 或 3:4

## 6. 页面背景与配色

- 主背景：`#F7F1E5`
- 某些模块可使用轻微更深一点的分区色：`#F3EEE3`
- 边框：`#E7D8C3`
- 标题：`#171412`
- 主红：`#9F1D1D`
- 金色：`#C9A45C`
- Footer 深红：`#8F1717`
