# 00 总说明

## 目标

继续精细化 Red Window Art 首页，使页面从“结构正确但偏简化”的状态，提升到“风格、气质、素材完整度都更接近设计稿”的状态。

## 当前问题（基于当前实现截图）

1. Hero 右侧场景过于简化，缺少木质、光影、装裱、花枝、书架等细节。
2. Collections / Gifts / Artworks 区域仍以占位图为主，缺少真正可用的视觉素材。
3. Craft Story 模块的质感还不够像真实品牌页面。
4. 页面整体“家居艺术品牌感”不够强。
5. 当前版本更像线框化品牌站，而不是成熟的 DTC 独立站首页。

## 本包要解决什么

1. 直接提供 Hero 场景图。
2. 直接提供 Featured Collections 卡片图。
3. 直接提供 Craft Story 横幅图。
4. 直接提供 Meaningful Chinese Gifts 卡片图。
5. 直接提供 Featured Artworks 商品图。
6. 给出可执行的详细任务书，让 Trae 只需要编程实现，不需要再进行设计判断。
