# 02 视觉令牌与实现约束

## 1. 配色

- 背景主色：`#F7F1E5`
- 正文：`#171412`
- 深棕：`#3B2A1F`
- 品牌主红：`#9F1D1D`
- 辅助红：`#B73A2F`
- 古金：`#C9A45C`
- 卡片底：`#FFF9EF`
- 边框：`#E7D8C3`
- 次级文字：`#6A5A49`
- 底部红：`#8F1717`
- 木质色：`#6B3F1D`

## 2. 字体

- 标题：`Georgia, 'Times New Roman', serif`
- 正文：`system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`

## 3. 圆角和阴影

- 卡片圆角：8px ~ 12px
- 图片卡片圆角：10px 左右
- 阴影要非常轻，避免厚重悬浮感

## 4. 容器宽度

- 主容器建议：`min(1180px, calc(100% - 48px))`
- 桌面端 section 上下间距：56px 左右

## 5. 实现约束

### 必须做
- 必须优先保证整体气质
- 必须保留模块顺序
- 必须保留品牌名 Red Window Art
- 必须实现“右侧家居场景 Hero”
- 必须实现礼品与寓意导向

### 不要做
- 不要做 Shopify 默认模板感
- 不要做普通 SaaS landing page 风格
- 不要高饱和亮红大面积铺满
- 不要蓝紫渐变
- 不要过多动画
- 不要外链随机图片

## 6. 开发建议

如果没有真实图片，推荐组合使用：
- CSS 渐变
- 内嵌 SVG
- 背景纹理 SVG
- 伪元素阴影
- 几何块模拟木柜 / 墙面 / 画框 / 窗影 / 花枝

目标不是“完全像素级复制”，而是“气质高度一致，布局结构非常接近”。
