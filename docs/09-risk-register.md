# 09 - 风险清单

文档版本：v0.2 中文版  
项目名称：蔚纸东方 / Yuxian Paper Art

## 1. 技术风险

| 风险 | 说明 | 影响 | 应对 |
|---|---|---|---|
| Medusa 初始化复杂 | 新版本项目结构、依赖和命令可能变化 | 后台启动受阻 | 分任务推进，先跑通最小后台 |
| DeepSeek 自行发挥 | 可能重构过度或改错方向 | 代码失控 | 每个任务包明确“不做什么” |
| 前台与后台字段不一致 | Medusa 字段和前台字段不同 | 页面数据错乱 | 建立 adapter 层 |
| 支付集成复杂 | 跨境支付服务商选择影响大 | 交易闭环延迟 | MVP 阶段不接真实支付 |
| 视觉跑偏 | AI 编码容易做成普通模板站 | 品牌价值下降 | 使用明确视觉规范和截图审查 |
| 依赖过多 | 引入过多 UI 库或复杂包 | 维护成本上升 | MVP 控制依赖，优先自定义组件 |
| 环境变量泄露 | 真实密钥被提交 | 安全风险 | `.env` 加入 `.gitignore`，只提交 `.env.example` |
| 本地服务冲突 | 端口被占用 | 启动失败 | 文档中明确端口，报错后逐项排查 |

## 2. 产品风险

| 风险 | 说明 | 影响 | 应对 |
|---|---|---|---|
| 用户不理解蔚县剪纸价值 | 海外用户可能不知道是什么 | 转化率低 | 强化故事、工艺、礼品场景 |
| 商品看起来太便宜 | 容易被认知为旅游纪念品 | 品牌溢价不足 | 高级视觉、包装、详情页叙事 |
| 首页缺少信任感 | 新品牌需要建立信任 | 用户跳出 | 增加工艺说明、运输说明、品牌故事 |
| 商品图不足 | 没有真实高质量图会影响转化 | 页面质感不足 | MVP 用占位，后续补拍或 AI 辅助图 |
| 文案过度文化化 | 用户看不懂 | 购买阻力增加 | 英文前台文案要简单、具体、可感知 |
| 商品场景不足 | 用户不知道怎么用 | 购买动机弱 | 增加家居、礼品、收藏场景 |

## 3. 运营风险

| 风险 | 说明 | 影响 | 应对 |
|---|---|---|---|
| 物流成本不清晰 | 跨境商品运输复杂 | 定价困难 | 后续单独设计物流策略 |
| 退换货政策不清晰 | 海外用户重视售后 | 信任不足 | 后续补充 policy 页面 |
| 支付服务商限制 | 中国公司接跨境支付有门槛 | 无法收款 | Phase 7 单独调研 |
| 包装不匹配定位 | 包装廉价会破坏品牌 | 用户体验下降 | 设计礼品包装和故事卡 |
| 供应链不稳定 | 手工艺品交付周期不稳定 | 发货延迟 | 建立库存和预售规则 |
| 客服语言问题 | 面向海外用户需要英文客服 | 售后压力 | 准备英文客服模板 |

## 4. 市场风险

| 风险 | 说明 | 影响 | 应对 |
|---|---|---|---|
| 目标国家选择不准 | 不同市场对中国文化接受度不同 | 投放浪费 | 先小范围测试 |
| 广告获客成本高 | 高端文化商品需要教育用户 | ROI 低 | 用内容种草和 SEO 降低成本 |
| 同类低价商品竞争 | 平台上可能有便宜剪纸 | 价格锚点被拉低 | 强化手工、故事、包装和场景 |
| 文化表达误读 | 海外用户理解可能不同 | 品牌传播受阻 | 文案避免晦涩和过度玄学 |
| 礼品场景不明确 | 用户不知道何时购买 | 购买频次低 | 重点设计婚礼、乔迁、节日场景 |

## 5. 协作风险

| 风险 | 说明 | 影响 | 应对 |
|---|---|---|---|
| Trae 修改范围过大 | 一次改太多导致难审查 | 质量不可控 | 每次只发一个任务包 |
| 运行结果不完整 | 没有报错和文件列表 | 难以定位问题 | 要求 Trae 完成后固定输出 |
| 人工协调遗漏 | 用户中间传递信息不完整 | 决策偏差 | 每次反馈包含命令、报错、截图、目录 |
| 文档不同步 | 代码和文档脱节 | 后续混乱 | 关键变更后更新 docs |
| 没有阶段验收 | 写完就继续下一步 | 问题累积 | 每个 Phase 必须验收后继续 |

## 6. 当前最高风险

当前阶段最高风险是：

```txt
前台视觉被 AI 编码做成普通商城模板。
```

应对方式：

1. 先用明确视觉规范约束。
2. 每次让 Trae 输出页面截图。
3. 先审查首页，再继续做深层功能。
4. 不要过早接复杂后台和支付。
5. 产品详情页必须强调文化叙事。

## 7. 风险处理优先级

优先处理：

1. 视觉跑偏。
2. 项目结构混乱。
3. 商品数据分散。
4. 任务范围失控。
5. 无法启动。
6. 移动端崩坏。
7. 环境变量泄露。

后续处理：

1. 支付服务商选择。
2. 物流方案。
3. 多语言。
4. SEO 内容系统。
5. 自定义后台。
