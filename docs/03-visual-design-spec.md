# 03 - 视觉设计规范

文档版本：v0.2 中文版  
适用阶段：Phase 1 起  
项目名称：蔚纸东方 / Yuxian Paper Art

## 1. 总体视觉方向

网站应该呈现：

1. 高端东方手工艺。
2. 温润。
3. 克制。
4. 有文化感。
5. 有博物馆礼品店气质。
6. 有现代家居适配感。
7. 有礼品属性。
8. 高级但不冰冷。

网站不能呈现：

1. 淘宝风。
2. 低价批发感。
3. 过度中国红。
4. 赛博风。
5. 游戏风。
6. 花哨渐变。
7. 复杂动效。
8. 信息拥挤。
9. 网红廉价促销风。

## 2. 视觉关键词

给编码代理的视觉关键词：

```txt
museum gift shop
oriental paper art
handcrafted heritage
warm luxury
elegant
calm
poetic
premium but not cold
```

中文解释：

1. 博物馆礼品店。
2. 东方纸艺。
3. 手工非遗。
4. 温润高级。
5. 优雅。
6. 安静。
7. 有诗意。
8. 高级但不冰冷。

## 3. 色彩规范

| 用途 | 色值 | 使用说明 |
|---|---|---|
| 背景主色 | `#F7F1E5` | 大面积页面背景，模拟宣纸米白 |
| 深色文字 | `#171412` | 主标题、正文主要文字 |
| 辅助深棕 | `#3B2A1F` | 导航、局部标题、沉稳辅助色 |
| 中国朱红 | `#B73A2F` | CTA、强调、少量装饰 |
| 古金色 | `#C9A45C` | 细线、标签、装饰点缀 |
| 浅卡片色 | `#FFF9EF` | 商品卡片、信息卡片背景 |
| 边框浅色 | `#E7D8C3` | 卡片边框、分割线 |

## 4. 色彩使用原则

1. 米白做大面积背景。
2. 墨黑和深棕做文字。
3. 朱红只做 CTA、强调和少量装饰。
4. 古金色只做细线、标签和装饰。
5. 不要大面积使用纯红。
6. 不要使用强烈荧光色。
7. 不要使用高饱和渐变堆叠。
8. 页面整体应有留白和呼吸感。

## 5. 布局原则

1. 大量留白。
2. 内容块之间距离充足。
3. 卡片使用轻边框和轻阴影。
4. 图片区域可以先使用抽象占位图形。
5. 首屏必须有强品牌感。
6. 产品卡片不应像普通商品货架，要像艺术品陈列。
7. 页面节奏应慢一点、稳一点，不要像促销活动页。
8. 重要 CTA 要清晰，但不要过度刺激。

## 6. 字体与排版

原则：

1. 英文标题要有高级感。
2. 正文可读性优先。
3. 标题字号大，正文不要过密。
4. 行高舒适。
5. 避免过多装饰字体。
6. 一个页面不要使用过多字体层级。
7. 商品名要清晰，描述要有文化感。

建议：

1. 标题使用较大的字号和宽松行距。
2. 正文使用中等字号，保证移动端可读。
3. 标签文字可以小一些，但不能过轻。
4. CTA 按钮文字要清晰直接。

## 7. 图像占位规范

在真实商品图未准备前，使用抽象视觉占位。

占位图要求：

1. 宣纸纹理感。
2. 剪纸轮廓感。
3. 窗棂构图。
4. 柔和阴影。
5. 朱红与金色点缀。
6. 不出现文字。
7. 不使用真实人物。
8. 不使用低质量图标拼贴。

Hero 视觉占位建议：

1. 大卡片。
2. 米白或浅卡片底色。
3. 朱红剪纸轮廓感图形。
4. 古金细线。
5. 微弱纸纹或背景装饰。
6. 轻阴影。
7. 边角不宜过圆，保持克制高级。

商品卡片占位建议：

1. 每个商品可以用不同抽象轮廓。
2. 保持统一风格。
3. 不要让占位图显得像普通渐变色块。
4. 可以使用 CSS 伪元素、圆形、镂空边框、剪影感图案表达纸艺。

## 8. 动效规范

MVP 阶段只使用轻微动效：

1. hover 轻微上浮。
2. 卡片阴影轻微变化。
3. 按钮颜色轻微变化。
4. 页面进入不需要复杂动画。
5. 不要滚动视差堆叠。
6. 不要大面积炫酷动效。

动效目标：

```txt
增强质感，而不是炫技。
```

## 9. 首页视觉要求

首页必须给用户一种感觉：

```txt
这是一个有文化、有审美、有品位的东方手工艺品牌。
```

首页不应该给用户一种感觉：

```txt
这是一个卖便宜中国风纪念品的网站。
```

首页 Hero 要：

1. 有品牌主张。
2. 有清晰行动按钮。
3. 有高质量视觉占位。
4. 有东方纸艺气质。
5. 有现代空间感。

## 10. 产品列表页视觉要求

产品列表页要像艺术陈列，而不是货架。

要求：

1. 商品卡片有留白。
2. 价格不能过度突出成促销样式。
3. 标签要克制。
4. 查看详情入口要优雅。
5. 商品标题要像作品名，而不是 SKU 名。

## 11. 产品详情页视觉要求

产品详情页要把商品从“剪纸”提升为“文化艺术礼物”。

要求：

1. 首屏视觉足够大。
2. 商品信息清晰。
3. 工艺、材料、尺寸、运输说明独立展示。
4. 文化故事要有阅读感。
5. CTA 明确但不廉价。
6. 推荐商品区域要保持统一气质。

## 12. 移动端视觉要求

移动端必须：

1. 保持足够留白。
2. 按钮足够大。
3. 字体可读。
4. 商品卡片不拥挤。
5. Hero 不要因双栏布局压缩变形。
6. 导航简洁。
7. 不出现横向滚动。
