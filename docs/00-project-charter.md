# 00 - 项目章程

文档版本：v0.2 中文版  
项目名称：蔚纸东方 / Yuxian Paper Art  
仓库名：yuxian-paper-art  
当前阶段：MVP 构建前规划阶段

## 1. 项目背景

本项目计划构建一个面向海外用户的跨境电商独立站，核心商品为中国非物质文化遗产相关产品。第一阶段聚焦“蔚县剪纸”。

项目不是普通低价小商品商城，而是希望通过品牌叙事、东方审美、礼品场景、家居装饰价值、收藏价值与手工艺文化，提升产品认知和品牌溢价能力。

## 2. 项目愿景

打造一个具有东方审美和文化深度的高端手工艺独立站。

用户购买的不只是商品，而是一份来自中国传统文化的艺术体验、礼物意义和生活美学。

## 3. 项目核心目标

第一阶段目标不是直接构建完整商业闭环，而是完成一个可运行、可展示、可扩展的 MVP 独立站。

MVP 需要做到：

1. 前台页面具备完整品牌体验。
2. 商品信息可以被清晰展示。
3. 用户可以完成从首页到商品详情、购物车、结账占位的基础路径。
4. 后台使用开源电商系统管理商品、价格、库存、订单等基础能力。
5. 架构为后续真实支付、物流、多语言、SEO、内容运营预留扩展空间。

## 4. 产品定位

品牌定位：

```txt
东方手工艺与现代家居礼品结合的高端文化电商独立站。
```

关键词：

1. 中国民俗艺术。
2. 蔚县剪纸。
3. 手工非遗。
4. 文化礼品。
5. 东方家居装饰。
6. 博物馆礼品店气质。
7. 温润高级。
8. 有诗意的手工艺。
9. 有意义的礼物。

## 5. 用户不是在买什么

用户不是单纯购买：

1. 一张纸。
2. 一个便宜装饰品。
3. 一个中国风纪念品。
4. 一个普通工艺品。
5. 一个旅游小商品。

## 6. 用户真正想要什么

用户真正想要的是：

1. 一个有故事的礼物。
2. 一个能体现审美和品味的家居装饰物。
3. 一个来自东方文化的独特艺术品。
4. 一个可以被朋友询问、讨论、赞美的物件。
5. 一份具有文化温度和手工痕迹的收藏。
6. 一个和普通批量工业商品不同的选择。

## 7. 核心价值主张

英文前台主张：

```txt
Heritage Cut by Hand, Light Framed for Modern Homes.
```

中文解释：

```txt
用手工剪出的非遗文化，用现代方式装进海外家庭的日常生活。
```

## 8. 目标用户

### 8.1 海外家居装饰消费者

特征：

1. 注重家居氛围。
2. 喜欢有文化感的小众艺术品。
3. 愿意为独特设计和手工价值付费。
4. 常见于欧美、澳洲、中高收入家庭。

购买动机：

1. 装饰客厅、玄关、书房、卧室。
2. 寻找不同于常规海报和装饰画的艺术品。

### 8.2 礼品购买者

特征：

1. 需要购买有意义、不俗套的礼物。
2. 场景包括乔迁、婚礼、节日、生日、商务礼品。

购买动机：

1. 送出一份有文化解释空间的礼物。
2. 礼物看起来不廉价、不普通。
3. 礼物背后有祝福和故事。

### 8.3 中国文化兴趣用户

特征：

1. 对东方文化、民俗艺术、传统工艺感兴趣。
2. 可能购买过茶具、书法、香、瓷器、中国风装饰。

购买动机：

1. 收藏。
2. 学习文化。
3. 布置具有东方氛围的空间。

### 8.4 博物馆礼品店风格消费者

特征：

1. 喜欢有文化解释和设计感的商品。
2. 接受高于普通装饰品的价格。
3. 看重包装、故事卡、出处和工艺说明。

购买动机：

1. 商品背后有故事。
2. 设计具有艺术和文化属性。

## 9. MVP 非目标

MVP 阶段暂不做：

1. 真实支付接入。
2. 复杂会员系统。
3. 完整物流系统。
4. 多语言完整翻译系统。
5. 自研后台管理系统。
6. 复杂营销活动系统。
7. 复杂库存与仓储系统。
8. App、小程序或第三方平台同步。
9. 大规模内容管理系统。

## 10. 成功标准

技术成功标准：

1. 前台能本地启动。
2. 后台能在后续阶段本地启动。
3. 商品列表和详情页能展示。
4. 页面结构清晰。
5. 代码结构可维护。
6. 后续能顺利接入 Medusa。
7. 环境变量不泄露真实密钥。

产品成功标准：

1. 首页能在 5 秒内让用户理解这是一个高端东方手工艺站。
2. 商品不是“便宜剪纸”，而是“文化艺术礼品”。
3. 产品详情页能解释工艺、材料、尺寸、场景和礼品价值。
4. 移动端体验可用。
5. 页面视觉和品牌定位一致。
